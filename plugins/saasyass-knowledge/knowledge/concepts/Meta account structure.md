# Meta account structure

Watch: [Account Structure Map](https://www.instagram.com/reel/DeAWutMuVv3/)

One consolidated campaign beats many small ones for B2B SaaS.

## Structure

- One campaign, broad targeting, 20-30 genuinely different ads (different pain, outcome, on-screen person). See [[Creative as targeting]].
- Budget floor around $150/day per ad set (*claimed*). If you can fund only one ad set at that level, run one. Many $50 experiments never leave learning ([[Conversion signal quality]]).

## Judging and scaling

- Do not judge on day three. Let an ad set spend about the price you would pay for one new customer, and let good ones run to roughly double.
- Once working, raise budget 10-30% every two to three days while sales can handle the call volume.

## Refresh when the winner tires

- Signal: cost per call climbs and call count falls for three or four days.
- Duplicate the winning ad set, put 30 new ads in the copy, pause the tired one. Never inject tests into the live winner.
- Mix of the 30 (*claimed*): 70% close remakes of the winner, 20% same message in a new style, 10% new ideas.

## Test vs scale

Testing budgets and structure differ: see [[ABO vs CBO]] and [[Market vote positioning]] (a $50/day per-idea test is a positioning experiment, not a steady-state account).
