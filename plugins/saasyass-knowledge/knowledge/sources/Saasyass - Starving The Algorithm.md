# Starving The Algorithm

- **Watch:** https://www.instagram.com/reel/DduWy0AB7Ih/
- **Date:** 2026-09-25
- **Playbook:** [[playbook]]

**Thesis:** Lead quality decays when Meta lacks conversions, so feed it a more frequent buyer-meaning event and consolidate ad sets.

## Doctrine

- Meta tests an ad on likely buyers first, then moves to colder buckets if nothing converts; thin data pushes it into junk audiences.
- Learning needs roughly 50 conversions a week in one ad set; below that, 'learning limited'. Splitting a few conversions across many ad sets makes it worse.
- Fix 1: optimise for a more frequent event that still implies buyer (qualified form submit, cold-offer opt-in).
- Fix 2: send rep-qualified leads from the CRM back via Conversions API.
- Fix 3: fewer ad sets, more ads each.
- Cost check: at a given cost per qualified lead the weekly target implies a daily budget in one ad set; if unaffordable, find a cheaper qualified event.

## Numbers

- 50 conversions/week/ad set; at $150 per qualified lead about $1,000/day (all *claimed*).
