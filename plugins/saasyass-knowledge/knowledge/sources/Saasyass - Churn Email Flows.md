# Churn Email Flows

- **Watch:** https://www.instagram.com/reel/Dd_yjwMTr3u/
- **Date:** 2026-10-02
- **Playbook:** [[playbook]]

**Thesis:** Churn gives warning signs; three behaviour-triggered email flows catch it before cancellation.

## Doctrine

- Retention is about leaks: a steady monthly churn rate compounds into losing about half the base within a year.
- No-login flow: find the longest normal gap between logins for an active user, double it, and trigger when someone exceeds it. Content: remind of results, show current customer wins, answer the usual excuse with a same-industry story.
- Low-usage flow: map which features create results, how often and which combine; email the moment a user drifts off that path (skipped key feature, too rare, over-reliance on one thing).
- Cancellation-page flow: several visits to the cancel page in a week signals intent. Do not announce you watched them; instead answer the three most common cancel reasons in a friendly FAQ-style email.
- All three only work if emails react to in-product behaviour.

## Numbers

- About 6% monthly churn and roughly half gone in a year (*claimed* illustrative figure).
